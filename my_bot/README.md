# Telegram Bot с локальной LLM (HK-47)

Telegram-бот с локальной языковой моделью GGUF, работающей через `llama-cpp-python`.

## Возможности

- Общение с локальной языковой моделью.
- Сохранение истории диалогов в SQLite.
- Контекст последних сообщений при генерации ответов.
- Фильтрация сообщений.
- Запись событий и ошибок в JSONL-лог.
- Стиль ответов HK-47 из Star Wars: KOTOR.

## Требования

- Windows 10/11.
- Python 3.10.
- Telegram-аккаунт.
- GGUF-модель, совместимая с `llama-cpp-python`.
- Достаточно оперативной памяти и ресурсов видеокарты для выбранной модели.

## 1. Создание Telegram-бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и username бота.
4. Скопируйте полученный API-токен. Он понадобится при настройке проекта.

**Не публикуйте токен в открытом доступе.**

## 2. Подготовка проекта

Скачайте репозиторий:

```powershell
git clone https://github.com/KnigaMichail/chat_bot_gguf.git
cd chat_bot_gguf
```

Создайте папку для моделей:

```powershell
mkdir models
```

Поместите скачанную GGUF-модель в эту папку. Например:

```text
chat_bot_gguf/
├── models/
│   └── model.gguf
├── bot.py
├── config.py
├── local_gpt.py
├── database.py
├── utils.py
├── requirements.txt
└── README.md
```

Сама модель в репозиторий не входит. Её необходимо скачать отдельно.

## 3. Настройка переменных окружения

В корневой папке проекта создайте файл `.env`.

Пример содержимого:

```env
TG_TOKEN=токен_вашего_бота
MODEL_PATH=models/model.gguf
TEMPERATURE=0.3
MAX_TOKENS=350
```

Замените значения на свои.

**Важно:** в текущей версии `local_gpt.py` путь к модели, температура и количество токенов заданы непосредственно в коде. Поэтому изменения `MODEL_PATH`, `TEMPERATURE` и `MAX_TOKENS` в `.env` пока не влияют на генерацию. Для использования этих настроек необходимо подключить их в `local_gpt.py`.

## 4. Установка зависимостей

Создайте виртуальное окружение:

```powershell
py -3.10 -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

В `requirements.txt` перечислены:

- `pyTelegramBotAPI` — взаимодействие с Telegram API.
- `llama-cpp-python` — запуск локальной GGUF-модели.
- `python-dotenv` — чтение переменных из `.env`.

**Примечание:** установка `llama-cpp-python` с поддержкой CUDA на Windows может потребовать отдельной настройки сборки. Установка зависимостей сама по себе не гарантирует работу GPU-ускорения.

## 5. Запуск бота

После настройки окружения и модели выполните:

```powershell
python bot.py
```

Если настройки корректны, бот подключится к Telegram и начнёт принимать сообщения.

## 6. Логи и база данных

При работе проекта используются:

- `bot_history.db` — база данных истории сообщений.
- `bot_logs.jsonl` — журнал событий и ошибок.

Логи записываются в формате JSONL. Для ограничения размера журнала используется ротация файлов.

## Безопасность

Не загружайте в публичный репозиторий:

- `.env` — содержит Telegram-токен.
- `.venv/` — виртуальное окружение.
- `models/` — файлы языковых моделей.
- `*.db` — локальные базы данных.
- `*.jsonl` — журналы работы бота.

Для этого используйте `.gitignore`.
